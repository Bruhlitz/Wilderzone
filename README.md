# WILDERZONE

A high-speed skiing and jetpack shooter from **Copper Key Studio**: ski the slopes, jet into the air, and fight for the flag.

## Download

**[Download the latest version for Windows](https://github.com/Bruhlitz/Wilderzone/releases/latest/download/Wilderzone-Windows.zip)**

Every version, with its release notes and the downloads for each platform (Windows, Linux, Android, Meta Quest), is on the **[Releases page](https://github.com/Bruhlitz/Wilderzone/releases)**, under **Assets**.

## Install on Windows

1. Download **Wilderzone-Windows.zip**.
2. Right-click it and choose **Extract All**.
3. Open the extracted folder and run **SkiForever.exe**.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The game isn't signed yet.

## Playing online

Everyone in a match needs the same version. When a new version comes out, download it again.
